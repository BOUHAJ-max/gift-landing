احتراف Termux وLinux على Android

تعلم إعداد بيئة عمل قوية على هاتفك، وإدارة الملفات والحزم والمشاريع والخدمات المحلية بطريقة صحيحة وآمنة.

ماذا ستنجز؟

بنهاية الدورة ستكون قادراً على إعداد Termux، تثبيت أدوات تطوير أساسية، تنظيم مجلداتك، تشغيل سكربت Python، إدارة مشروع Git، وتشغيل خادم محلي للاختبار على هاتفك.

الوحدة 1: التثبيت والتحقق من المصدر

  1. افتح صفحة المشروع الرسمية: Termux على GitHub.
  2. اقرأ تعليمات التثبيت والإصدارات المدعومة.
  3. لا تخلط تطبيق Termux وإضافاته من مصادر أو توقيعات مختلفة.
  4. افتح الطرفية وانتظر اكتمال الإعداد الأولي.
تطبيق: اكتب مصدر التنزيل وإصدار التطبيق وتاريخ التثبيت في ملف ملاحظات.

الوحدة 2: تحديث الحزم وإدارة المستودعات

حدّث فهارس الحزم ثم ثبّت التحديثات المتاحة:

pkg update
pkg upgrade

ثبّت مجموعة أدوات بداية:

pkg install git python nano curl wget openssh

استكشف المساعدة والحزم المثبتة:

pkg help
pkg list-installed
تطبيق: نفّذ التحديث، ثم اكتب أسماء خمس حزم ثبتّها ولماذا تحتاج إليها.

الوحدة 3: الملفات والتخزين والصلاحيات

تعرف على المسار الحالي والمجلدات والنسخ والنقل والحذف الآمن:

pwd
ls -la
mkdir -p ~/projects
cd ~/projects
touch notes.txt
cp notes.txt notes-copy.txt
mv notes-copy.txt backup.txt

لإتاحة التخزين المشترك، نفّذ termux-setup-storage وراجع إذن Android قبل الموافقة. لا تستخدم الحذف التكراري على مسارات غير متأكد منها.

تطبيق: أنشئ هيكل مجلدات projects وdownloads وbackups، وانسخ ملفاً تجريبياً إلى مجلد النسخ الاحتياطية.

الوحدة 4: أدوات التطوير

شغّل Python وتحقق من الإصدارات:

python --version
python -c "print('Hello from Termux')"
node --version

يمكن تثبيت Node.js عند الحاجة عبر pkg install nodejs. لا تثبّت حزم مشاريع مجهولة قبل مراجعة اسمها ومصدرها.

تطبيق: أنشئ برنامجاً صغيراً يطبع التاريخ أو يحسب مجموع رقمين، ثم احفظه في مجلد projects.

الوحدة 5: Git وإدارة الإصدارات

cd ~/projects
mkdir my-first-project
cd my-first-project
git init
printf "# My first project\n" > README.md
git status

تعلم الفرق بين working tree وstaging area وcommit. لا ترفع كلمات المرور أو مفاتيح API أو ملفات النسخ الاحتياطية إلى مستودع عام.

تطبيق: أنشئ أول commit محلياً بعد إضافة README، ثم راجع سجل التغييرات.

الوحدة 6: SSH والشبكات المحلية

تعرف على مفهوم العميل والخادم والمنافذ والمفاتيح العامة والخاصة. استخدم SSH للاتصال بأجهزتك فقط، واحمِ المفتاح الخاص ولا ترسله لأحد.

ssh -V
ip route
ping -c 3 127.0.0.1

قد تختلف الأدوات بحسب إصدار Android والحزم المثبتة. لا تفحص أجهزة أو شبكات لا تملكها أو لا تملك إذناً صريحاً لاختبارها.

تطبيق: ارسم مخطط اتصال منزلي بسيط وحدد الأجهزة التي تملك صلاحية إدارتها.

الوحدة 7: المشروع الختامي

أنشئ مجلداً منظماً لمشروعك، واكتب سكربت Python بسيطاً، ووثّق طريقة تشغيله في README، ثم احفظ التغييرات في Git.

mkdir -p ~/projects/termux-final
cd ~/projects/termux-final
printf 'print("BOUHAJ TECH")\n' > main.py
python main.py
git init
git add README.md main.py
git status
معيار الإنجاز: مشروع يعمل دون أخطاء، وملف README يشرح التثبيت والتشغيل، وسجل Git منظم.
