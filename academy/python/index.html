Python من الصفر إلى المشاريع

ابنِ أساساً متيناً في البرمجة بلغة Python، ثم طبّق ما تعلمته في مشروع عملي صغير قابل للتطوير.

النتيجة التي تستهدفها

كتابة برامج صغيرة مفهومة، تقسيم العمل إلى دوال، التعامل مع البيانات والملفات، قراءة رسائل الخطأ، وتنظيم مشروع يمكن لشخص آخر تشغيله.

الوحدة 1: بيئة العمل وأول برنامج

ثبّت Python من مصدر موثوق، وتحقق من الإصدار ثم شغّل:

python --version
python -c "print('Hello, BOUHAJ TECH!')"
تمرين: اطبع اسمك وهدفك من تعلم البرمجة في ثلاثة أسطر منفصلة.

الوحدة 2: المتغيرات وأنواع البيانات

name = "Learner"
age = 20
hours = 2.5
is_learning = True
print(name, age, hours, is_learning)
print(type(age))

تعلم النصوص والأعداد الصحيحة والعشرية والقيم المنطقية، والتحويل بين الأنواع باستخدام int وfloat وstr عند الحاجة.

تمرين: أنشئ متغيرات لاسم كتاب وسعره وعدد نسخه، ثم اطبع ملخصاً منسقاً.

الوحدة 3: الشروط واتخاذ القرار

score = 82
if score >= 90:
    print("Excellent")
elif score >= 60:
    print("Passed")
else:
    print("Try again")

افهم المقارنات وand وor وnot، وانتبه إلى المسافات البادئة لأنها جزء من بنية Python.

تمرين: اكتب برنامجاً يحدد إن كان الرقم موجباً أو سالباً أو صفراً.

الوحدة 4: الحلقات والتكرار

for number in range(1, 6):
    print(number)

count = 3
while count > 0:
    print(count)
    count -= 1

اختر for عندما يكون التكرار على مجموعة أو نطاق معروف، واستخدم while عندما يعتمد الاستمرار على شرط واضح.

تمرين: اطبع جدول ضرب رقم يختاره المستخدم، مع التحقق من صحة الإدخال.

الوحدة 5: القوائم والقواميس

courses = ["Python", "Linux", "Security"]
student = {"name": "Ali", "level": "beginner"}
courses.append("Git")
print(courses[0])
print(student.get("name"))

القائمة تحفظ عناصر مرتبة، والقاموس يربط المفاتيح بالقيم. استخدم البنية المناسبة لطبيعة البيانات.

تمرين: أنشئ قاموساً لمنتج يحتوي الاسم والسعر والكمية، ثم احسب القيمة الإجمالية للمخزون.

الوحدة 6: الدوال وتنظيم الكود

def calculate_total(price, quantity):
    return price * quantity

total = calculate_total(12.5, 4)
print(total)

تعلم المعاملات والقيم المعادة والنطاق المحلي للمتغيرات، واجعل كل دالة تؤدي مهمة واضحة.

تمرين: اكتب دالة تحوّل الدرهم إلى السنتيم، ودالة أخرى تحسب متوسط ثلاث علامات.

الوحدة 7: الملفات ومعالجة الأخطاء

from pathlib import Path

path = Path("notes.txt")
path.write_text("My first Python file", encoding="utf-8")
print(path.read_text(encoding="utf-8"))

try:
    number = int(input("Enter a number: "))
except ValueError:
    print("Please enter a valid integer")

استخدم UTF-8 للنصوص، وتعامل مع الأخطاء المتوقعة برسائل مفيدة. لا تبتلع الاستثناءات بصمت.

تمرين: أنشئ برنامج ملاحظات بسيطاً يضيف سطراً إلى ملف ويعرض محتواه.

الوحدة 8: المشروع النهائي — مدير مصروفات نصي

أنشئ برنامجاً يسجل وصف المصروف وقيمته وتاريخه في ملف CSV، ويعرض مجموع المصروفات. قسّم المشروع إلى دوال: إضافة سجل، قراءة السجلات، حساب المجموع، والتحقق من الإدخال.

  • تحقق من أن المبلغ رقم موجب.
  • لا تمسح الملف عند إضافة سجل جديد.
  • تعامل مع الملف غير الموجود بإنشاء ترويسة مناسبة.
  • أضف README يشرح طريقة التشغيل والاختبار.
معيار الإنجاز: يستطيع مستخدم جديد تشغيل البرنامج وإضافة ثلاثة مصروفات ورؤية مجموع صحيح دون فقدان البيانات.
