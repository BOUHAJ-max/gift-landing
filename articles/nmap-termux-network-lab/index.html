تثبيت Nmap على Termux وفحص مختبرك الشبكي بأمان

تعلم تثبيت Nmap وقراءة الإصدار وفحص جهاز تملكه أو لديك إذن صريح لاختباره داخل شبكة مختبرية.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

Nmap أداة لاستكشاف الشبكات والخدمات. استخدمها حصراً على أجهزتك أو في مختبر لديك تصريح واضح لاختباره؛ لا تفحص أنظمة عامة دون إذن.

تثبيت Nmap

ثبّت الحزمة من مستودعات Termux، ثم اعرض رقم الإصدار للتأكد من التثبيت.

تحديد نطاق الاختبار

قبل الفحص، حدد جهازاً تجريبياً تملكه أو شبكة مختبرية مصرحاً لك بها. لا تعتبر اتصالك بشبكة عامة إذناً بفحص أجهزتها.

pkg install nmap
nmap --version
# استبدل العنوان بعنوان جهاز مختبرك المصرح به
nmap -sV 192.168.1.10

فحص جهاز واحد

يمكن إجراء فحص أساسي لعنوان جهاز داخل مختبرك. استبدل العنوان بعنوان الجهاز التجريبي الصحيح.

قراءة النتائج

تعرض النتائج المنافذ التي ظهرت أثناء الفحص وحالة كل منها، وقد تتضمن أسماء خدمات وتخمينات إصدار. لا تعني النتيجة وحدها وجود ثغرة.

إعلان

تقليل المخاطر

تجنب الفحص الواسع أو المتكرر على شبكات لا تديرها. احتفظ بنطاق الاختبار مكتوباً، وأوقف الفحص إذا طلب مالك النظام ذلك.

الأوامر في هذا الدرس

pkg install nmap
nmap --version
# استبدل العنوان بعنوان جهاز مختبرك المصرح به
nmap -sV 192.168.1.10

ملاحظة: قد تختلف بعض التفاصيل بحسب إصدار Android وإصدار Termux والمستودعات المتاحة. راجع الوثائق الرسمية عند ظهور اختلاف.
