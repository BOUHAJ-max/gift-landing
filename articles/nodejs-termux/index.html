تثبيت Node.js وNPM على Termux وتشغيل JavaScript

خطوات تثبيت Node.js في Termux والتحقق من node وnpm وتشغيل أول أمر JavaScript.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

يوفر Node.js إمكانية تشغيل JavaScript خارج المتصفح. في Termux يمكنك تثبيته من مدير الحزم ثم تجربة الشيفرة مباشرة.

تثبيت Node.js

استخدم مدير الحزم لتثبيت Node.js من مستودعات Termux. لا تحتاج إلى تنزيل ملفات تنفيذية من مواقع غير معروفة.

التحقق من التثبيت

اعرض إصدار node وإصدار npm للتأكد من أن الأدوات متاحة في PATH.

pkg install nodejs
node --version
npm --version
node -e "console.log('Hello from Termux')"
printf "console.log('My first script')\n" > app.js
node app.js

تشغيل JavaScript مباشرة

يمكن تمرير تعليمة قصيرة إلى node باستخدام الخيار -e، وهي طريقة سريعة لاختبار البيئة.

إنشاء ملف JavaScript

أنشئ ملفاً بامتداد js واكتب داخله تعليمة console.log، ثم شغله باستخدام node واسم الملف.

إدارة الحزم بأمان

عند استخدام npm، تحقق من اسم الحزمة وسمعتها ووثائقها، ولا تشغّل سكربتات غير موثوقة قبل مراجعة ما تفعله.

إدارة مشروع Node.js

ابدأ مجلد مشروع مستقل، ثم أنشئ ملف إعدادات npm. اقرأ ملف package.json قبل تشغيل أوامر المشروع، لأنه قد يحتوي سكربتات تنفذ أوامر على جهازك.

mkdir -p ~/projects/node-lab
cd ~/projects/node-lab
npm init -y
printf 'console.log("Node project ready");\n' > app.js
node app.js

استخدم npm install فقط بعد مراجعة الاعتماديات، وتجنب تثبيت الحزم العالمية دون حاجة واضحة.

تشخيص أخطاء Node وnpm

  • إذا ظهر command not found فتحقق من تثبيت Node.js ومن PATH.
  • إذا فشل تثبيت حزمة، اقرأ اسم الحزمة وإصدار Node ورسالة npm قبل إعادة المحاولة.
  • إذا ظهر خطأ module not found، تأكد من أنك داخل مجلد المشروع وأن الاعتمادية مسجلة فيه.
  • لا تحذف ملف القفل lockfile عشوائياً؛ فهو يساعد على تثبيت نسخ اعتماديات متسقة.
node --version
npm --version
npm ls --depth=0
