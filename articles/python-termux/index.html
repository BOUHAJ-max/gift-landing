تثبيت Python على Termux وتشغيل أول برنامج

دليل تثبيت Python في Termux، والتحقق من الإصدار وإنشاء ملف hello.py وتشغيله وتثبيت المكتبات.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

يمكنك تعلم Python مباشرة من هاتف Android باستخدام Termux. سنثبت المفسر، ننشئ ملفاً بسيطاً، ثم نشغله من الطرفية.

تثبيت Python والتحقق

ثبّت حزمة Python من مستودعات Termux، ثم اطلب من المفسر عرض رقم الإصدار للتأكد من نجاح التثبيت.

إنشاء مشروع

أنشئ مجلداً مخصصاً لمشاريعك وانتقل إليه. فصل ملفات المشاريع يساعدك على التنظيم وتجنب خلط التجارب.

pkg install python
python --version
mkdir -p ~/projects
cd ~/projects
nano hello.py
# اكتب: print('Hello from Termux!')
python hello.py

كتابة أول برنامج

افتح محرر nano وأنشئ ملف hello.py. اكتب سطر طباعة بسيطاً، ثم احفظ الملف واخرج من المحرر.

تشغيل البرنامج

نفّذ الملف باستخدام أمر python متبوعاً باسم الملف. إذا ظهر النص في الطرفية فقد عمل البرنامج كما ينبغي.

تثبيت المكتبات

استخدم pip عبر python -m pip عند الحاجة إلى مكتبة. اقرأ توثيق المكتبة وتأكد من توافقها مع بيئة Android قبل تثبيتها.

تشغيل سكربت منظم ومعالجة الإدخال

بعد نجاح أول برنامج، افصل الكود في ملف واحرص على التحقق من مدخلات المستخدم. المثال التالي يحسب مجموع رقمين ويتعامل مع الإدخال غير الرقمي:

def main():
    try:
        first = float(input("First number: "))
        second = float(input("Second number: "))
    except ValueError:
        print("Please enter valid numbers.")
        return
    print("Total:", first + second)

if __name__ == "__main__":
    main()

شغّله باستخدام python app.py، ثم جرّب أرقاماً صحيحة ومدخلات غير صالحة ولاحظ الفرق.

تنظيم المشروع والمكتبات

أنشئ مجلد مشروع مستقل، واحتفظ بملف README يشرح طريقة التشغيل. عندما تحتاج مكتبة خارجية، تحقق من توثيقها وتوافقها مع Termux وAndroid قبل تثبيتها.

mkdir -p ~/projects/my-python-app
cd ~/projects/my-python-app
python -m pip --version
python -m pip install requests

ليس كل مشروع Python يحتاج إلى مكتبات خارجية. ابدأ بمكتبات Python القياسية عندما تفي بالغرض، ولا تنفّذ تعليمات تثبيت من مصدر غير موثوق.

تمرين: أنشئ برنامجاً يحوّل درجات الحرارة بين Celsius وFahrenheit، واكتب في README مثالين للمدخلات والنتائج المتوقعة.
