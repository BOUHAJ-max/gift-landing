تشغيل خادم ويب محلي على Termux باستخدام Python

طريقة تشغيل خادم HTTP محلي على هاتفك باستخدام Python مع ربطه بعنوان loopback وإيقافه بأمان.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

يمكنك تشغيل خادم HTTP بسيط داخل Termux لمعاينة ملفات مشروعك على الهاتف. هذا مناسب للتجارب المحلية وليس بديلاً عن استضافة إنتاجية.

تجهيز مجلد التجربة

أنشئ مجلداً منفصلاً وضع فيه ملفات HTML التجريبية فقط. لا تشغّل الخادم من مجلد يحتوي على مستندات خاصة أو مفاتيح سرية.

تشغيل الخادم

انتقل إلى المجلد وشغّل خادم Python على المنفذ 8000 مع ربطه بواجهة loopback حتى يكون الوصول محلياً على الجهاز.

mkdir -p ~/web-demo
cd ~/web-demo
printf '<h1>Hello from Termux</h1>\n' > index.html
python -m http.server 8000 --bind 127.0.0.1
# افتح http://127.0.0.1:8000 في المتصفح
إعلان

فتح الصفحة

افتح متصفح الهاتف واكتب عنوان localhost مع المنفذ المحدد. ستظهر قائمة الملفات أو صفحة index.html إذا كانت موجودة.

إيقاف الخادم

ارجع إلى Termux واضغط Ctrl+C لإيقاف العملية. أغلق جلسة الطرفية عند الانتهاء.

حدود هذا الخادم

خادم Python المدمج مخصص للتطوير والاختبار البسيط. لا تعرضه للإنترنت العام دون تصميم نشر آمن ومراجعة إعدادات الحماية.
