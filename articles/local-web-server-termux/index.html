تشغيل خادم ويب محلي على Termux باستخدام Python

طريقة تشغيل خادم HTTP محلي على هاتفك باستخدام Python مع ربطه بعنوان loopback وإيقافه بأمان.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

يمكنك تشغيل خادم HTTP بسيط داخل Termux لمعاينة ملفات مشروعك على الهاتف. هذا مناسب للتجارب المحلية وليس بديلاً عن استضافة إنتاجية.

تجهيز مجلد التجربة

أنشئ مجلداً منفصلاً وضع فيه ملفات HTML التجريبية فقط. لا تشغّل الخادم من مجلد يحتوي على مستندات خاصة أو مفاتيح سرية.

تشغيل الخادم

انتقل إلى المجلد وشغّل خادم Python على المنفذ 8000 مع ربطه بواجهة loopback حتى يكون الوصول محلياً على الجهاز.

mkdir -p ~/web-demo
cd ~/web-demo
printf '<h1>Hello from Termux</h1>\n' > index.html
python -m http.server 8000 --bind 127.0.0.1
# افتح http://127.0.0.1:8000 في المتصفح

فتح الصفحة

افتح متصفح الهاتف واكتب عنوان localhost مع المنفذ المحدد. ستظهر قائمة الملفات أو صفحة index.html إذا كانت موجودة.

إيقاف الخادم

ارجع إلى Termux واضغط Ctrl+C لإيقاف العملية. أغلق جلسة الطرفية عند الانتهاء.

حدود هذا الخادم

خادم Python المدمج مخصص للتطوير والاختبار البسيط. لا تعرضه للإنترنت العام دون تصميم نشر آمن ومراجعة إعدادات الحماية.

تغيير مجلد الخدمة والمنفذ

يمكنك تحديد مجلد الملفات صراحةً باستخدام --directory، واختيار منفذ محلي متاح. اربط الخادم بعنوان loopback حتى لا تعرض الملفات لأجهزة الشبكة دون قصد:

mkdir -p ~/web-demo/public
printf '
Local demo
\n' > ~/web-demo/public/index.html
python -m http.server 8080 --bind 127.0.0.1 --directory ~/web-demo/public

افتح http://127.0.0.1:8080 على الهاتف نفسه. أوقف الخادم باستخدام Ctrl+C عند الانتهاء.

أخطاء الوصول وحدود الاستخدام

  • إذا كان المنفذ مستخدماً، اختر منفذاً آخر مثل 8081.
  • إذا ظهر Directory listing بدلاً من صفحة، تحقق من اسم index.html ومجلد الخدمة.
  • إذا لم يفتح الرابط، تأكد من أن الخادم ما زال يعمل وأن العنوان والمنفذ صحيحان.
  • لا تستخدم خادم التطوير المدمج لاستضافة بيانات خاصة أو موقع إنتاجي.

الخادم المرتبط بـ127.0.0.1 لا يستقبل عادة اتصالات الأجهزة الأخرى. لا تغيّر العنوان إلى 0.0.0.0 إلا إذا كنت تفهم أثر إتاحة الخدمة على الشبكة وتملك إذناً وإعدادات حماية مناسبة.

تمرين: شغّل خادماً محلياً على 8080، افتح الصفحة من متصفح الهاتف، ثم أوقفه وتحقق من أن الاتصال لم يعد متاحاً.
