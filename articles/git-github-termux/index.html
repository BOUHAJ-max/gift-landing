استخدام Git وGitHub من Termux على هاتف Android

شرح تثبيت Git وتهيئة الاسم والبريد وإنشاء مستودع محلي واستنساخ مشروع من GitHub.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

يساعدك Git على تتبع تغييرات ملفاتك، بينما يتيح GitHub استضافة المستودعات والتعاون عليها. يمكنك تنفيذ أساسيات Git من هاتفك عبر Termux.

تثبيت Git

ثبّت Git من مستودعات Termux ثم تحقق من الإصدار. استخدم البريد والاسم اللذين تريد ظهورهما في سجل الالتزامات.

تهيئة الهوية

اضبط user.name وuser.email على مستوى المستودع أو البيئة. لا تضع كلمات المرور أو رموز الوصول ضمن إعدادات عامة أو ملفات منشورة.

pkg install git
git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
mkdir my-project && cd my-project
git init
echo "# My project" > README.md
git status

إنشاء مستودع محلي

أنشئ مجلداً للمشروع، ثم نفّذ git init. أضف ملفاً تجريبياً وافحص الحالة بواسطة git status.

استنساخ مستودع

استخدم git clone مع رابط المستودع الذي تملكه أو تريد المساهمة فيه. راجع عنوان URL قبل تشغيله.

رفع التغييرات

قبل push، افهم طريقة المصادقة التي تستخدمها GitHub. لا تشارك Personal Access Token في الصور أو الرسائل أو أوامر محفوظة.

المصادقة مع GitHub دون كشف الأسرار

لا تقبل GitHub كلمات المرور العادية للمصادقة عبر Git على HTTPS. استخدم طريقة مصادقة مدعومة مثل GitHub CLI أو Personal Access Token بصلاحيات محدودة أو SSH. لا تلصق الرمز داخل ملف أوامر أو محادثة، ولا تحفظه في مستودع.

راجع صلاحيات الرمز وتاريخ انتهائه، وألغِه فوراً إذا ظهر في سجل أو صورة أو ملف عام. عند استخدام SSH، احفظ المفتاح الخاص محلياً ولا تشاركه.

مراجعة التغييرات قبل الرفع

قبل إرسال commit إلى مستودع عام، راجع الملفات والفرق النصي:

git status
git diff --cached
git log --oneline -5

تأكد من عدم وجود ملفات .env أو كلمات مرور أو مفاتيح خاصة أو نسخ احتياطية. إذا أضفت سراً إلى commit، فحذفه في commit لاحق لا يزيله من التاريخ؛ ألغِ السر من الخدمة أولاً ثم اتبع إجراء تنظيف التاريخ المناسب.

تمرين: أنشئ README بسيطاً، راجع التغييرات باستخدام git diff، ثم أنشئ commit برسالة واضحة دون إضافة ملفات غير لازمة.

الأوامر في هذا الدرس

pkg install git
git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
mkdir my-project && cd my-project
git init
echo "# My project" > README.md
git status
