تنبيه أمني: استخدم أدوات الشبكات على أجهزتك أو الشبكات التي تملكها أو لديك إذن صريح لاختبارها. هذا الدليل للتعلم والإدارة المشروعة، وليس لاختراق حسابات أو أجهزة الآخرين.

1. ما هو Termux؟

Termux تطبيق يوفر طرفية وبيئة Linux على Android دون الحاجة إلى صلاحيات Root. تستطيع من خلاله إدارة الملفات، تثبيت أدوات التطوير، تشغيل Python وNode.js، واستخدام Git وبعض أدوات الشبكات.

هو ليس توزيعة Linux كاملة بواجهة رسومية افتراضياً؛ بل بيئة سطر أوامر قابلة للتوسّع بحزم تُثبّت عند الحاجة.

2. تثبيت Termux بطريقة صحيحة

  1. نزّل Termux من مصدره الرسمي الموثوق مثل صفحة المشروع على GitHub أو F-Droid.
  2. تحقق من اسم المطوّر والمصدر قبل التثبيت، وتجنب ملفات APK المعدّلة أو المواقع المجهولة.
  3. إذا احتجت إضافات Termux، ثبّتها من المصدر نفسه الذي ثبّت منه التطبيق؛ لا تخلط نسخاً بتوقيعات مختلفة.
  4. افتح التطبيق وانتظر ظهور سطر الأوامر.

المصدر: مستودع Termux الرسمي · صفحة Termux على F-Droid.

3. التحديث الأول وتجهيز البيئة

ابدأ بتحديث قوائم الحزم ثم تثبيت التحديثات المتاحة:

pkg update && pkg upgrade

قد يُطلب منك تأكيد العملية بكتابة y ثم الضغط على Enter. بعد ذلك ثبّت أدوات أساسية تحتاجها كثيراً:

pkg install git python nano curl wget

لفهم المساعدة العامة:

pkg help
pkg list-installed

4. أهم أوامر Linux للمبتدئين

  • pwd عرض المسار الحالي.
  • ls عرض الملفات والمجلدات.
  • ls -la عرض الملفات المخفية والتفاصيل.
  • cd اسم_المجلد الدخول إلى مجلد.
  • cd .. الرجوع إلى المجلد السابق.
  • mkdir projects إنشاء مجلد.
  • touch note.txt إنشاء ملف فارغ.
  • cp source.txt copy.txt نسخ ملف.
  • mv old.txt new.txt نقل ملف أو تغيير اسمه.
  • cat note.txt عرض محتوى ملف نصي.
  • rm note.txt حذف ملف؛ لا تستخدمه قبل التأكد من الاسم والمسار.
تحذير: الأمر rm -rf قد يحذف مجلدات كاملة دون طلب تأكيد. لا تنسخه من الإنترنت عشوائياً ولا تستخدمه على مسارات لا تعرفها.

5. الوصول إلى ملفات الهاتف

لإتاحة مجلد التخزين المشترك للتطبيق، نفّذ:

termux-setup-storage

وافق على إذن الوصول الذي يعرضه Android. بعد ذلك ستجد اختصارات التخزين داخل:

ls ~/storage
cd ~/storage/shared

لا تمنح تطبيقات غير موثوقة صلاحيات الوصول إلى ملفاتك، ولا تضع كلمات المرور أو المفاتيح الخاصة في مجلدات مشتركة.

6. تثبيت Python وتشغيل أول برنامج

pkg install python
python --version

أنشئ ملفاً بسيطاً:

mkdir -p ~/projects
cd ~/projects
nano hello.py

اكتب داخله:

print("Hello from Termux!")

احفظ في nano باستخدام Ctrl+O ثم Enter، واخرج بـ Ctrl+X، ثم شغّل:

python hello.py

لتثبيت مكتبة لمشروعك، استخدم python -m pip install اسم_المكتبة بعد قراءة توثيقها ومصدرها.

7. تثبيت Node.js

pkg install nodejs
node --version
npm --version

جرّب JavaScript مباشرة:

node -e "console.log('Hello from Node.js')"

يمكنك إنشاء مشروع خاص بك داخل ~/projects وتثبيت الحزم التي يحتاجها فقط، مع مراجعة اسم الحزمة ومصدرها قبل التثبيت.

8. استعمال Git وGitHub

Git يساعدك على تتبع تغييرات ملفات مشاريعك. ابدأ بإنشاء مجلد مشروع:

pkg install git
mkdir my-project
cd my-project
git init
echo "# My project" > README.md
git status

لنسخ مستودع عام تملكه أو تريد المساهمة فيه:

git clone https://github.com/USERNAME/REPOSITORY.git

لا تضع رمز الوصول الشخصي (Token) أو كلمة المرور داخل ملف منشور أو أمر محفوظ في سجل الطرفية. استخدم وسائل المصادقة الرسمية والآمنة.

9. أساسيات الشبكات وتجربة Nmap بإذن

يمكن استخدام أدوات الشبكات لفهم الأجهزة والخدمات في مختبرك المنزلي أو شبكة تملك تصريحاً لاختبارها. ثبّت Nmap:

pkg install nmap
nmap --version

في مختبرك فقط، يمكنك فحص جهاز محدد تعرف عنوانه وتملك الإذن لفحصه:

nmap -sV 192.168.1.10

استبدل العنوان بعنوان جهازك التجريبي. لا تفحص نطاقات عامة أو شبكات الآخرين دون موافقة واضحة ومسبقة.

10. تشغيل خادم ويب محلي

لخدمة ملفات مجلد محلياً على هاتفك، انتقل إلى المجلد ثم شغّل خادم Python على واجهة loopback:

cd ~/projects
python -m http.server 8000 --bind 127.0.0.1

افتح المتصفح على الهاتف واكتب http://127.0.0.1:8000. لإيقاف الخادم ارجع إلى Termux واضغط Ctrl+C.

هذا خادم تجريبي بسيط وليس استضافة إنتاجية. لا تعرض مجلدات تحتوي على ملفات خاصة، ولا تربطه بالإنترنت العام دون إعداد حماية مناسب.

حل مشكلات شائعة

الحزم لا تُحدّث

تأكد من اتصال الإنترنت ثم جرّب:

pkg update

الأمر غير موجود

تحقق من اسم الحزمة وثبّتها باستخدام pkg install اسم_الحزمة إذا كانت متاحة في مستودعات Termux.

امتلأت مساحة التخزين

اعرف حجم المجلدات قبل حذف أي شيء. لا تنفّذ أوامر حذف جماعية لا تفهمها.

توقفت العملية أو تريد الخروج

استخدم Ctrl+C لإيقاف الأمر الجاري، وCtrl+D لإنهاء جلسة الطرفية في الحالات المناسبة.

تعلم Termux بالتجربة الهادئة: افهم الأمر، جرّبه داخل مجلد تجريبي، ثم انتقل إلى الخطوة التالية. لا تحتاج إلى تنفيذ عشرات الأوامر دفعة واحدة؛ الاستمرار والفهم أهم من السرعة.
