تحديث Termux وتثبيت الحزم الأساسية خطوة بخطوة

تعلم أوامر pkg update وpkg upgrade وإعداد Termux بأدوات Git وPython وNano وCurl بطريقة صحيحة.

إعداد: Mohamed Bouhaj · دليل مجاني · قراءة عملية

بعد تثبيت Termux، ابدأ بتحديث قوائم الحزم قبل تثبيت الأدوات. هذه الخطوة تقلل مشاكل الاعتماد على معلومات قديمة في مدير الحزم.

تحديث قوائم الحزم

الأمر الأول يحدّث فهارس الحزم المتاحة في المستودعات، ولا يعني وحده ترقية كل البرامج المثبتة.

ترقية الحزم المثبتة

بعد تحديث الفهارس، نفّذ الترقية. اقرأ ما يعرضه مدير الحزم قبل الموافقة، خصوصاً إذا كانت هناك تغييرات كبيرة.

pkg update
pkg upgrade
pkg install git python nano curl wget
pkg list-installed

تثبيت أدوات البداية

يمكنك تثبيت محرر نصوص وأدوات تنزيل وإدارة إصدارات لتسهيل الدروس اللاحقة. ثبّت ما تحتاجه فقط حتى لا تستهلك مساحة الهاتف دون داعٍ.

أوامر مفيدة للتحقق

استخدم أوامر المساعدة وقائمة الحزم المثبتة لمعرفة حالة البيئة. إذا فشل التحديث، تحقق من اتصال الإنترنت والمستودع ورسالة الخطأ كاملة.

متى أعيد المحاولة؟

إذا ظهرت أخطاء مرآة المستودع أو انقطاع الاتصال، أعد المحاولة بعد استقرار الإنترنت، ولا تنفذ أوامر حذف عشوائية لمعالجة مشكلة لا تعرف سببها.

فهم رسائل مدير الحزم

يمثل pkg واجهة مبسطة لإدارة الحزم في Termux. يقوم pkg update بتحديث قوائم الحزم المتاحة، بينما يقوم pkg upgrade بترقية الحزم المثبتة. لا يعني تحديث القوائم وحده أن البرامج المثبتة أصبحت محدثة.

اقرأ ملخص العمليات قبل الموافقة، وانتبه إلى الحزم التي ستزال أو تستبدل. إذا كان التغيير كبيراً، احفظ ملفات مشاريعك أولاً وتأكد من توفر مساحة كافية.

pkg update
pkg list-upgradable
pkg upgrade

التعامل مع فشل المستودعات

عند فشل الوصول إلى مرآة مستودع، ميّز بين مشكلة الإنترنت ومشكلة المرآة. جرّب شبكة أخرى، وتحقق من إعدادات التاريخ والوقت، ثم استخدم أداة تغيير المرآة الرسمية المتاحة في نسختك عند الحاجة.

  • لا تحذف مجلدات الحزم يدوياً.
  • لا تضف مستودعات مجهولة أو مفاتيح توقيع غير موثوقة.
  • احتفظ برسالة الخطأ كاملة عند طلب المساعدة، مع حذف أي بيانات خاصة.
تمرين: حدّث الفهارس، ثم اعرض الحزم المثبتة وسجّل ثلاث حزم تستخدمها وسبب حاجتك إليها.

الأوامر في هذا الدرس

pkg update
pkg upgrade
pkg install git python nano curl wget
pkg list-installed

ملاحظة: قد تختلف بعض التفاصيل بحسب إصدار Android وإصدار Termux والمستودعات المتاحة. راجع الوثائق الرسمية عند ظهور اختلاف.
